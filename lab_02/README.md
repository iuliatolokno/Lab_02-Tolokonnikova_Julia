# toolkit

Пакет streamstats, читающий события CVS и JSONL и создающий статистический отчёт.

## Установка

Из папки `lab_02`:

    pip install -e .

## Функционал

    1. Пакет читает входные файлы построчно.
    2. Поддерживается CVS с заголовком и JSONL.
    3. Считает общее число событий.
    4. Считает количество событий каждого уровня и источника.
    5. Находит первую и последнюю временную ветку.
    6. Формирует JSON-отчёт.
    7. Объединяет стаитистику.

## Ошибочные строки

Режим работает по умолчанию. Выводит номер файла и строки, завершает CLI с кодом 2.
Режим --skip-invalid : пропускает строку, записываем WARNING в лог и добавляет число пропущенных строк в отчёт.

## Запуск

    py -m src.streamstats --help // объясняет как запускать программу

    py -m src.streamstats INPUT [INPUT ...] --format cvs|jsonl --output report.json

    py -m src.streamstats INPUT [INPUT ...] --format cvs|jsonl --output report.json --skip-invalid
